Amazon 主图 Suppressed 怎么办？12 个常见图片不合规原因 + 修复方案

Listing 被搜索屏蔽 80% 是图片问题。本文按出现频率列出 12 个原因，每条附症状、原因、修复方法和复审流程。

所谓 Suppressed，是 Amazon 后台把你的 listing 从搜索结果里"藏起来"——商品页面还在、外链能访问，但用户搜不到，相当于直接断流量。运营报表里通常表现为"昨天 100 单，今天 0 单"。

触发 Suppressed 的原因有几十种（标题、bullet、关键词、合规、品类受限……），但实际跑下来，大约 80% 是图片不合规。Amazon 的图片审核对中国卖家尤其严，因为机审 + 人审都比欧美卖家更频繁。

本文列出 2025 年至今我们和合作卖家遇到最多的 12 个图片不合规原因 + 修复方法。

怎么判断自己被 Suppressed 了

三个入口都看一下，任何一个有红色提示就要立刻查图：

  1. Seller Central → Inventory → Manage All Inventory：列表里 Status 列变成 "Inactive (Image)" 或 "Suppressed"
  2. Seller Central → Catalog → Manage All Listings：黄色或红色感叹号，悬停看 "Listing has been suppressed"
  3. Seller Central → Performance → Notifications：会收到"Your listing is no longer available for sale" 邮件

  1. 背景不是 RGB 纯白（最常见）
  2. 主图含价格 / 促销 / "Best Seller" 文字
  3. 长边 < 1000px，无法触发 Zoom
  4. 产品占图 < 85%
  5. 含卖家水印 / logo
  6. 含其他电商 logo（eBay / Walmart / Etsy）
  7. 模特戴帽 / 口罩 / 墨镜遮脸
  8. 主图是拼图（多张小图组合）
  9. 主图含赠品 / 配件（不在售卖范围）
  10. 颜色配置不是 sRGB
  11. 服装类只有平铺图，无穿着状态
  12. 含违禁元素（裸露 / 血腥 / 武器 / 假冒品牌）

1. 背景不是 RGB 纯白（255,255,255）

症状：肉眼看像白底，但机审判定为"off-white"。

原因：很多自拍 / 棚拍图实际背景 RGB 是 250-254 之间的"米白"或"奶白"，Amazon 机审要求严格 255,255,255。

修复：

  • Photoshop：图层 → 新建调整图层 → 色阶，把输入色阶白点拉到 245-250 之间
  • 免费工具：Photoroom / Remove.bg 抠图 → 填充 #FFFFFF 背景
  • AI 出图：直接生成 RGB 255 背景，零返工（Crosslify 默认输出符合 Amazon 主图规范）
💡 验证工具：QQ 截图 / macOS 数码测色仪 / Photoshop 吸管，吸图片四角，看 RGB 值是否 255,255,255。

2. 主图含价格 / 促销 / "Best Seller" 文字

症状：图片明显有 "50% OFF""SALE""FREE SHIPPING""Best Seller" 等文字标识。

原因：Amazon 明令禁止主图含任何促销 / 价格 / 排名文字。即使产品本身贴了"Limited Edition"标签，也会被机审误判。

修复：

  • 所有促销文字移到副图（PT01-PT08 副图允许）
  • 产品本身的标签是否能用？Amazon 实操规则：产品自带的固有标签（如 logo、洗水标）OK，外贴的促销贴纸（如 "30% OFF"）不行

3. 长边 < 1000px，无法触发 Zoom

症状：用户进商品页，鼠标 hover 主图没有放大镜效果。

原因：Amazon zoom（放大镜）功能要求主图最长边 ≥ 1000px。低于这个值不会直接 Suppressed 但会影响转化（用户看不清细节）；后续机审升级到 1500px 触发线，低于 1500px 也开始报警。

修复：

  • 推荐尺寸：1600×1600 至 2000×2000，正方形
  • 不要把小图放大（会糊）：要从源文件重新出图
  • AI 出图：直接生成 2000×2000 高清，零损失

4. 产品占图 < 85%

症状：产品周围留白太多，机审判定"product not prominent"。

原因：Amazon 要求主图中产品（包括包装）占据画面长边的 ≥ 85%。常见踩坑：小件珠宝 / 配件类，原图产品很小而背景很大。

修复：

  • 用 Photoshop 裁切到产品占画面 85-90%
  • 注意：裁切后整图尺寸不能 < 1000×1000（见 #3）

5. 含卖家水印 / logo

症状：图片角落有自己的店铺 logo、二维码、网址、电话。

原因：Amazon 禁止任何形式的"导流"和"卖家品牌外露"在主图上（副图也限制）。哪怕只是品牌 logo（除非是 Amazon 备案品牌且已上 Brand Registry），都可能被机审拦。

修复：彻底清除水印 / logo。如果是已注册 Brand Registry 的品牌，可在副图带 logo，但主图建议也清掉以求保险。

6. 含其他电商 logo（eBay / Walmart / Etsy）

症状：复用之前在其他平台的主图，没注意角落有 "eBay Top Seller" 或 "Etsy Star Seller" 标。

原因：Amazon 严打"其他平台水印"，即使是 review 截图带 eBay logo 也会被拦。

修复：换图。对每个平台维护单独的图库，不要复用。

7. 模特戴帽 / 口罩 / 墨镜遮脸

症状：服装、配饰类，模特脸部被遮挡。

原因：Amazon 要求服装类主图必须展示"完整穿着效果"，遮脸会被判"无法验证穿着状态"。但戴口罩 / 墨镜如果是产品本身（如卖墨镜）OK。

修复：

  • 主图换成不遮脸版本
  • 戴帽 / 墨镜的图可以放副图（lifestyle 场景图）
  • AI 出图：可以指定模特"无遮挡正面"，且能批量生成不同肤色 / 年龄段

8. 主图是拼图（多张小图组合）

症状：主图被拆成 2-4 块小图，分别展示不同角度 / 颜色 / 配件。

原因：主图必须是单张产品图。拼图允许放副图，但主图不行。

修复：主图保留产品最佳角度的单图，其他角度 / 颜色全部移到副图。

9. 主图含赠品 / 配件（不在售卖范围）

症状：卖 1 个 T 恤，主图里放了配套帽子 + 鞋子 + 配饰。

原因：Amazon 要求主图只展示"实际售卖的内容"。多余物品会让消费者误以为"买 1 送 N"，是误导性的。

修复：主图只放正在售卖的 SKU。组合套装可以单独建一个 listing 卖。

10. 颜色配置不是 sRGB

症状：图片在本地 Photoshop 看正常，上传到 Amazon 后颜色偏暗 / 偏黄。

原因：摄影师常用 Adobe RGB 或 ProPhoto RGB 出图（色域更广），但 Amazon 网页只支持 sRGB 显示。

修复：

  • Photoshop：编辑 → 转换为配置文件 → 选 sRGB IEC61966-2.1
  • Lightroom：导出时勾"sRGB"
  • AI 出图：fal.ai / SD 生成默认就是 sRGB

11. 服装类只有平铺图，无穿着状态

症状：T 恤、裙子、内衣等服装类，主图只有"平铺在桌子上"或"挂在衣架上"的图。

原因：服装类必须展示"穿着效果"（on-model 或 mannequin）。光鸭子（衣架）或平铺图算"无法验证版型"。

修复：

  • 找模特拍上身（外包 $50-300/SKU）
  • 用 mannequin（人台），但要看起来像真人形态（不要光秃秃的木头人台）
  • AI 出图：上传一张平铺图，Crosslify 自动生成上身效果（不同市场 / 不同模特），单次成本 ~$0.05

12. 含违禁元素（裸露 / 血腥 / 武器 / 假冒品牌）

症状：图中出现 Amazon 黑名单元素。

原因：Amazon 维护一个庞大的图像黑名单，命中即 Suppressed，严重的会封店。

修复：

  • 泳装 / 内衣：可以露但不能过度暴露，参考 Amazon Fashion 现有 listing 的尺度
  • 武器 / 仿真枪：很多类目直接禁，先查类目限制
  • 假冒品牌：不要 P logo 上去；不要用真品牌图片冒充自己产品

改完图后怎么申请复审

  1. 替换主图：Seller Central → 商品 → 编辑 → Images 标签，上传新图。注意：替换不是删除老图再传新图（会造成短时间无图），是直接覆盖。
  2. 等机审：通常 30 分钟 - 2 小时机审会自动重审，多数情况下符合规范就会自动解除 Suppressed。
  3. 如果机审没解：去 Seller Central → 帮助 → 联系我们 → 商品和库存 → 提交 case，附"已修复图片，请人审"说明 + 新图截图。人审通常 24-48 小时。
  4. 多次被拒：可能需要开 case 让客服解释具体哪条违规，机审有时会"哪都不告诉你哪里错"。

怎么从源头避免

事后修复总是被动 + 成本高（每次 Suppressed 至少 24 小时无销量）。三个源头方案：

  • 建立内部"主图 checklist"：每次上新，按本文 12 条逐条过
  • 批量预检：用 Helium 10 / Jungle Scout 的 Listing Optimizer 提前扫
  • 用 AI 出图工具：从生成阶段就遵守 Amazon 规范，零返工
